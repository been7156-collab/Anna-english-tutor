# ANNA 영어쌤

로컬에서 실행하는 영어 회화 AI 튜터 웹앱 MVP입니다.

## 기능
- 상황별 회화 테마 선택
- 한국어 질문 → 영어 추천 문장
- 영어 문장 교정 + 한국어 설명
- 빠른 도움 버튼(힌트, 정답, 숙어, 문법)
- 음성 인식(브라우저 지원 시)
- 마지막 답변 음성 읽기
- API 키 없이 데모 모드 체험
- OpenAI 호환 API 키 입력 시 실제 AI 응답 사용

## 실행
```bash
cd /Users/mac/english-ai-tutor
python3 -m http.server 8765
```

브라우저에서:
- http://127.0.0.1:8765

## 실제 AI 모드
왼쪽 설정 패널에 아래를 입력:
- API Key
- Base URL (기본: https://api.openai.com/v1)
- Model (예: gpt-4.1-mini)

주의:
- 브라우저에서 직접 OpenAI 호환 API를 호출하므로 키가 로컬 브라우저 localStorage에 저장됩니다.
- 개인 Mac에서만 테스트하세요.
- 배포용으로는 프록시 백엔드 추가가 좋습니다.
